# Quick Capture v5.0.0-beta.2

This beta updates the Rust screenshot backend packaging and installation flow.

## Highlights

- Publishes the Rust backend as a verified GitHub Release asset.
- Adds checksum-verified installation and local build scripts.
- Adds architecture-aware backend selection with clear fallback guidance.
- Improves selector responsiveness and preserves the existing Old Backend option.

Install the backend from [`dms-screenshot-rs/README.md`](../dms-screenshot-rs/README.md), then select **New Backend** in Quick Capture settings.
